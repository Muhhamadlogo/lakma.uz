# Индивидуальный проект (6 семестр): Онлайн-магазин автосалона

Готовый учебный проект по дисциплине **«Индивидуальный проект»**.
Тема: **веб-приложение автосалона** с каталогом автомобилей, регистрацией пользователей и отправкой заявок.

## Функциональность

- Каталог автомобилей с поиском и фильтрами.
- Страница детального просмотра автомобиля.
- Регистрация и авторизация пользователей.
- Отправка заявки на автомобиль (лид).
- Личный кабинет пользователя с историей заявок.
- Админ-панель для добавления автомобилей и просмотра всех заявок.
- Тестовое наполнение базы данных через `/seed`.

## Технологии

- Python 3.11+
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML + CSS

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

После запуска откройте: `http://127.0.0.1:5000`

### Начальные данные

1. Перейдите по адресу `http://127.0.0.1:5000/seed`.
2. Будут созданы тестовые автомобили и админ:
   - Логин: `admin@autosalon.uz`
   - Пароль: `admin123`
