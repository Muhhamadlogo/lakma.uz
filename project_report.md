# Отчёт по предмету «Индивидуальный проект»

## Тема проекта
**Онлайн-магазин автосалона** (веб-приложение для выбора автомобиля и отправки заявки).

## Цель
Разработать информационную систему, позволяющую:
- публиковать каталог автомобилей;
- фильтровать и искать автомобили;
- регистрировать пользователей;
- принимать заявки на покупку автомобиля;
- администрировать карточки автомобилей и просматривать поступившие заявки.

## Соответствие результатам обучения
- **РО1:** реализованы основные элементы управления проектом и этапы разработки.
- **РО2:** сформирован и реализован план (модели БД → backend → UI → тестирование).
- **РО3:** получены практические навыки full-stack разработки.
- **РО4:** продемонстрированы навыки реализации и сопровождения проекта.

## Архитектура решения
- **Представление:** HTML-шаблоны Jinja2 + CSS.
- **Бизнес-логика:** Flask Blueprint (`app/routes.py`).
- **Данные:** SQLite + SQLAlchemy (`User`, `Car`, `Order`).

## Основные модули
1. **Каталог автомобилей** — просмотр и фильтрация.
2. **Пользователи** — регистрация, вход/выход.
3. **Заявки** — создание и просмотр личной истории.
4. **Админ-панель** — добавление авто и просмотр всех заявок.

## База данных
Сущности:
- `User(id, full_name, email, password_hash, is_admin, created_at)`
- `Car(id, brand, model, year, price, mileage, fuel_type, transmission, description, photo_url, is_available, created_at)`
- `Order(id, user_id, car_id, phone, comment, status, created_at)`

Связи:
- `User 1..* Order`
- `Car 1..* Order`

## Безопасность
- Пароли хранятся в виде хэша (`werkzeug.security`).
- Защита маршрутов через декораторы (`login_required`, `admin_required`).

## Тестирование
Проведены базовые проверки:
- запуск приложения без ошибок;
- прохождение синтаксической проверки кода;
- ручная проверка регистрации, авторизации, создания заявки и админ-функций.

## Вывод
Цель проекта достигнута: разработано готовое веб-приложение автосалона, соответствующее требованиям учебной дисциплины «Индивидуальный проект».
